1. app.py — Application Entry Point

backend/app.py

This is the root Flask application file. It performs four tasks: creates the Flask app, initialises CORS and MongoDB, registers all Blueprints (sub-routers), and provides a static-file fallback to serve the React build.

Module-level setup

_DEBUG, _PORT — read from environment so Render can inject PORT. _FRONTEND_ORIGIN — used by CORS to allow the frontend origin. _DIST_DIR — path to backend/static/dist where the React build is placed after npm run build.

Flask app creation
app = Flask(__name__, static_folder=_DIST_DIR, static_url_path="/")
Flask is configured to serve files from the React build folder. CORS(app, ...) allows cross-origin requests from localhost:3000 and the production frontend URL. PyMongo(app) connects to MongoDB using the URI in Config.
init_app / init_db / init_otp_db
Each blueprint that needs database access exposes an init_*(mongo) function. App.py calls all four to inject the shared PyMongo instance. This avoids circular imports.
health()
GET /health → {status: "ok"}
Health-check endpoint used by Render/load-balancers. Always returns HTTP 200.
test_db()
GET /test_db → {status: "MongoDB connection successful"}
Inserts a {ping: "pong"} document into the test collection. Returns 500 if MongoDB is unreachable.
serve_react(path)
GET / and GET /<path:path>
The React SPA catch-all. Logic:
  • If the path starts with any known API prefix (predict, login, etc.) → return 404 JSON so API routes aren't swallowed.
  • If a static asset exists at that path → serve it directly (JS/CSS/fonts).
  • Otherwise → serve index.html (React handles the route client-side).
  • If no build exists → return a plain HTML message telling the developer to run npm run build.

3. routes/auth.py — Authentication

backend/routes/auth.py

Blueprint auth handles user registration, login, Google OAuth, and JWT-protected profile access.

init_app(db)
Stores the shared PyMongo instance in the module-level mongo global. Called once from app.py during startup.
_client_config()
→ dict
Builds the Google OAuth2 client configuration dictionary from environment variables. Used by google-auth-oauthlib's Flow.
_redirect_uri()
→ str
Returns the Google OAuth redirect URI from env vars (defaults to http://localhost:5000/auth/google/callback).
register() POST /register
Body: { name, email, password }
  • Validates all fields are present.
  • Checks email uniqueness in users collection.
  • Hashes password with bcrypt (salt rounds = 12 default).
  • Inserts user document with created_at: datetime.utcnow().
  • Returns 201 on success, 409 if email already registered.
login() POST /login
Body: { email, password } → { message, token }
  • Looks up user by email in MongoDB.
  • Verifies password with bcrypt.checkpw().
  • If valid, issues a JWT with {"email": ..., "exp": now+24h} signed with SECRET_KEY using HS256.
  • Returns 401 if email not found or password wrong.
token_required(f) — Decorator
Wraps any route that requires a valid JWT.
  • Extracts Bearer <token> from Authorization header.
  • Decodes JWT with SECRET_KEY and retrieves current_user from MongoDB.
  • Passes current_user as the first argument to the decorated function.
  • Returns 401 if token is missing, expired, or invalid.
profile(current_user) GET /profile
Protected by @token_required. Returns {name, email} for the authenticated user.
google_login() GET /auth/google
  • Checks that GOOGLE_CLIENT_ID is configured; returns 503 if not.
  • Creates a google_auth_oauthlib.flow.Flow with the three OpenID scopes.
  • Generates the Google authorization URL with access_type=offline, prompt=select_account.
  • Saves the OAuth state and optional PKCE code_verifier in the Flask session.
  • Redirects the browser to Google's consent screen.
google_callback() GET /auth/google/callback
Handles Google's redirect back after user grants permission.
  • Retrieves saved OAuth state from session.
  • Reconstructs the Flow with same state.
  • Calls flow.fetch_token(authorization_response=...) to exchange the code for tokens.
  • Verifies the ID token with Google's public keys via id_token.verify_oauth2_token().
  • Upserts user in MongoDB ($setOnInsert preserves existing data, $set name always updates).
  • Issues a 24-hour JWT and redirects to FRONTEND_ORIGIN/auth/callback?token=&name=&email=.
  • On any error → redirects to /login?error=....

4. routes/gesture.py — Gesture Prediction

backend/routes/gesture.py

Blueprint gesture receives MediaPipe landmark sequences from the browser and returns ML predictions.

predict() POST /predict
Body: { user_id, gesture: [[218 floats]×≤60], nmm: {…} }
  • Calls predict_gesture(gesture_input) from ml.predictor.
  • If successful, stores a record in gesture_history with gesture array, predicted text, confidence, top5, NMM, and timestamp.
  • Returns {predicted_text, confidence, top5, nmm}.
  • If model not loaded, includes warning and needs_retrain: true in response (still HTTP 200).
generate_sentence_route() POST /generate-sentence
Body: { glosses: string[], nmm: {…} } → { sentence, source }
Two-tier sentence generation:
  • Tier 1 (Watsonx): If is_configured(), builds a Llama-3 prompt with ASL gloss string and NMM context cues, calls wx_generate(), strips stop tokens.
  • Tier 2 (rule-based): Falls back to sentence_generator.generate_sentence(glosses, nmm) if Watsonx is unconfigured or throws.
  • Response includes source: "watsonx" or source: "rule-based".
predict_letter_route() POST /predict-letter
Body: { landmarks: [63 floats] } → { letter, confidence, top5, is_dynamic }
  • Validates that exactly 63 landmark floats are provided (21 hand points × 3 coords).
  • Delegates to predict_letter(landmarks) from ml.letter_predictor.
  • Returns top-1 letter with confidence and top-5 alternatives.
generate_letter_sentence_route() POST /generate-letter-sentence
Body: { letters: string } → { sentence, suggestions[], source }
Converts a fingerspelled letter string (e.g. "hlo") to the best matching English word. Uses Watsonx if configured (returns JSON word + suggestions), otherwise uses LetterSession.suggest() dictionary lookup.
model_status() GET /model/status
Returns live state of both ML models: gesture model loaded boolean, num_classes, first 5 label names; letter model loaded boolean, classes list, accuracy from meta.
model_reload() POST /model/reload
Calls reload_model() and reload_letter_model() to hot-reload model weights from disk without restarting Flask. Useful after retraining.

6. routes/text_to_sign.py — Text-to-Sign

backend/routes/text_to_sign.py

Module-level constants and initialisation

_VIDEOS_DIR — path to backend/data/WLASL/videos/. _JSON_PATH — path to curated_WLASL.json. _SPLIT_ORDER — preference ranking: val > train > test for picking the best video instance. Both _WORD_LOOKUP and _VOCAB_LIST are built at import time so each request is O(1).

_build_lookup() → dict
Reads curated_WLASL.json once at startup. For each entry:
  • Collects all video instances; separates those with local mp4 from those with only a remote CDN URL.
  • Sorts each group by _SPLIT_ORDER (val first = cleanest data).
  • Concatenates local-first, remote-second.
  • Maps word → [{ video_id, external_url }, ...].
_tokenise(text) → list[str]
Lowercases, strips non-alpha characters (keeps apostrophe), and splits on whitespace. E.g. "I'm happy!" → ["i'm", "happy"].
_stem_candidates(word) → list[str]
Applies a rule table of 28 suffix transformations (e.g. -ing → e, -tions → te, -ed → ""). For each derived stem, also collapses trailing double consonants (rr → r). Returns a deduplicated ordered list of stem candidates ≥ 3 chars.
_fuzzy_match(word) → str | None
  1. Tries all stem candidates in order; returns the first that exists in _WORD_LOOKUP.
  2. For words ≥ 5 chars, uses difflib.get_close_matches(word, _VOCAB_LIST, n=1, cutoff=0.80).
  3. Returns None if nothing matches.
_make_entry(matched_word, original_word, fuzzy) → dict
Builds the result dictionary for a matched word: original/matched word, found=True, fuzzy flag, video_id, video_url (/video/{id} if local file exists, else None), external_url (CDN), and all_entries list.
_resolve_tokens(tokens) → list[dict]
Main resolution loop. For each position i:
  1. Check bigram tokens[i] + " " + tokens[i+1] in lookup (compound ASL signs).
  2. Exact single-word lookup.
  3. Fuzzy/stem match via _fuzzy_match().
  4. If nothing found → {found: false, video_url: null}.
convert_text() POST /text-to-sign
Body: { text: string } → { words[], coverage, total_words, found_words }
Tokenises text, resolves each token, calculates coverage ratio (found/total), returns the full word array.
serve_video(video_id) GET /video/<video_id>
Validates video_id is 1–6 digits (prevents path traversal). Left-pads to 5 digits. Uses Flask's send_file(..., conditional=True) which supports HTTP Range requests (needed for HTML5 video seek). Returns 404 if mp4 not found locally.
vocabulary() GET /text-to-sign/vocabulary
Returns the full sorted vocabulary list and count. Used by the frontend to show supported words.
dataset_status() GET /text-to-sign/status
Reports whether the local WLASL video directory exists and how many mp4 files are present.

7. routes/ai.py — AI / Watsonx Endpoints

backend/routes/ai.py

Blueprint ai_bp (prefix /ai) provides five endpoints powered by IBM Watsonx.ai Llama-3.3-70B.

_unavailable() → Response (503)
Helper returning a standard 503 JSON error when Watsonx credentials are not set. Called at the top of any endpoint that requires AI.
improve_text() POST /ai/improve-text
Body: { text: string } → { improved: string }
Sends the raw sign-to-text output to Llama-3 with a system prompt instructing it to rewrite as fluent English (topic-comment → SVO, add articles/punctuation). Uses max_new_tokens=120, temperature=0.2. On error, returns the original text unchanged.
learning_tip() POST /ai/learning-tip
Body: { word: string } → { word, tip, fun_fact }
Asks Llama-3 to return JSON {"tip": "...", "fun_fact": "..."} for a given ASL sign word. Parses the JSON response; falls back to raw text if JSON parse fails.
sentence_insights() POST /ai/sentence-insights
Body: { translations: string[] } → { insights: string }
Takes up to 30 recent translated signs, joins them into a comma-separated string, asks Llama-3 to identify vocabulary themes, frequency patterns, one improvement suggestion, and one motivational observation. Returns plain prose.
gloss_to_english() POST /ai/gloss-to-english
Body: { glosses: string[], nmm: {…} } → { sentence, source }
Alternative route (same logic as gesture.generate_sentence_route but exposed under /ai/). Interprets NMM signals into natural-language cues appended to the prompt. Falls back to ml.sentence_generator if Watsonx unavailable.
letter_to_sentence() POST /ai/letter-to-sentence
Body: { letters: string } → { sentence, suggestions[], source }
Asks Llama-3 for the best English word matching fingerspelled letters, returning JSON with word and up to 3 suggestions. Falls back to LetterSession.suggest().
ai_status() GET /ai/status
Returns {configured: bool, model: "meta-llama/llama-3-3-70b-instruct" | null}. Safe to call with no credentials.

8. routes/otp.py — OTP Email Verification

backend/routes/otp.py
_gen_code() → str
Generates a random 6-digit string using random.choices(string.digits, k=6).
_send_email(to_addr, code) → None
Builds a branded HTML email (blue heading, large OTP digits, 10-minute expiry notice). Sends via smtplib.SMTP_SSL("smtp.gmail.com", 465) using Gmail app password. Raises RuntimeError if credentials missing.

Body: { email } → { message: "OTP sent" }

  • Upserts otp_codes collection (one active code per email).

Body: { email, code } → { valid: true }
Checks: record exists → not already verified → not expired → code matches. On success, sets verified=true in MongoDB. Returns 400 with specific error messages for each failure case.

9. services/watsonx.py — IBM Watsonx SDK

backend/services/watsonx.py

Wraps IBM Watsonx.ai REST API with IAM token caching.

Module-level state

MODEL_ID = "meta-llama/llama-3-3-70b-instruct" — the LLM used for all generation. _token_lock — threading Lock prevents concurrent IAM token refresh. _cached_token / _token_expiry — cached access token with expiry timestamp.

_get_iam_token() → str
Thread-safe. Checks if the cached token expires in > 60 seconds; if so, returns it. Otherwise calls IBM IAM (https://iam.cloud.ibm.com/identity/token) with a grant_type=apikey POST, caches the new token + expiry. Raises on HTTP error.
generate(prompt, max_new_tokens, temperature, stop_sequences) → str
  • Guards that both IBM_API_KEY and PROJECT_ID are set.
  • Gets a fresh IAM token via _get_iam_token().
  • POSTs to Watsonx generation endpoint with model_id, project_id, input prompt, and parameters (greedy if temperature=0, sample otherwise; repetition_penalty=1.1).
  • Returns results[0].generated_text stripped of whitespace.
is_configured() → bool
Returns True only if both IBM_API_KEY and WATSONX_PROJECT_ID env vars are non-empty. Does not make a network call.

10. ml/predictor.py — Gesture Inference

backend/ml/predictor.py

Loads the PyTorch GestureBridgeLSTM model at startup and exposes predict_gesture().

Module-level state

All model artefacts are stored as module globals: _model (GestureBridgeLSTM or None), _labels (dict idx→word), _num_classes, _feat_mean/_feat_std (normalizer arrays). Set by _initialize() on import.

_load_labels(labels_path) → dict
Reads labels.json and converts string keys to int: {"0": "hello"} → {0: "hello"}. Logs warning if file missing (predictions still work but return class_N strings).
_load_model(model_path, meta_path, num_classes) → GestureBridgeLSTM | None
  • Returns None if model file does not exist (server starts in degraded mode).
  • Reads model_meta.json to get num_classes, sequence_length, landmark_vector_size overriding module defaults.
  • Instantiates GestureBridgeLSTM(num_classes) and loads the state_dict with weights_only=True (security best practice).
  • Returns None on RuntimeError (size mismatch) with a helpful retrain message.
_initialize()
Orchestrates startup: calls _load_labels(), _load_model(), and loads normalizer.npz if present. Logs summary. Called automatically at module import time (line 111 _initialize()).
predict_gesture(landmark_sequence) → dict
landmark_sequence: ndarray or list shape (T, 218)
  • Returns error dict if model not loaded.
  • Converts input to float32 ndarray; reshapes 1D to 2D.
  • Calls pad_or_truncate(seq, 45) to ensure exactly 45 frames.
  • Applies z-score normalisation with loaded mean/std (if available).
  • Adds batch dimension, converts to PyTorch tensor.
  • Runs model.forward() under torch.no_grad().
  • Applies softmax to get probabilities.
  • Returns top-1 word + confidence + top-5 list.
reload_model()
Calls _initialize() again, replacing module globals. Called by POST /model/reload.

11. ml/letter_predictor.py — ASL Letter Inference

backend/ml/letter_predictor.py

Loads a scikit-learn classifier (RandomForest/SVC) for static ASL hand letter classification (A–Z minus J and Z which are dynamic).

Constants

ConstantValueMeaning
LETTER_CONF_THRESH0.70Minimum probability to commit a letter
STABLE_FRAMES_REQUIRED4Consecutive matching frames before commit
COOLDOWN_FRAMES10Frames to skip after a commit
TRAJ_BUFFER_SIZE15Index-tip trajectory window for J/Z detection
J_PATH_THRESH0.18Path length threshold for J stroke
Z_PATH_THRESH0.20Path length threshold for Z stroke
_load()
Tries to load model in two ways:
  1. Split files: asl_letter_model.joblib + asl_letter_scaler.joblib + asl_letter_meta.json
  2. Bundle fallback: asl_letter_bundle.joblib which contains {"model": ..., "label_encoder": ...}
Logs warning if neither is found.
predict_letter(raw_landmarks_63) → dict
raw_landmarks_63: list or array of 63 floats
  • Validates 63 input features (21 landmarks × 3 coords).
  • Optionally applies StandardScaler transform.
  • Calls model.predict_proba() → softmax probabilities.
  • Returns {letter, confidence, top5[{letter, confidence}], is_dynamic: False}.
_path_length(pts) → float
Sums Euclidean distances between consecutive (x,y) points. Used to measure how much the index fingertip has moved over the last 15 frames.
_bbox_aspect(pts) → float
Returns width/height ratio of the bounding box of trajectory points. J has aspect < 0.8 (vertical curve), Z has aspect > 1.2 (horizontal zigzag).

Class: LetterSession

Stateful per-session wrapper for real-time fingerspelling recognition. One instance per active video stream in the browser (instantiated inside SignToText.jsx).

LetterSession.push(raw_landmarks_63, index_tip_xy) → dict | None
Call once per video frame during fingerspelling mode.
  • Honours cooldown counter (skips frames after a commit).
  • Appends index_tip position to trajectory deque.
  • Calls predict_letter() for the static classification.
  • If trajectory is full (15 frames): computes path_length and aspect ratio; overrides letter to "J" or "Z" if thresholds met.
  • Increments stable counter when same letter appears with conf ≥ 0.70.
  • On stable_count ≥ STABLE_FRAMES_REQUIRED (4): appends letter to _word, resets counters, starts cooldown, returns commit dict with word and suggestions.
  • Returns None if no letter committed this frame.
LetterSession.suggest(partial, n=3) → list[str] [static]
Prefix-matches _WORD_LIST (80+ common words), then fuzzy-matches with cutoff 0.4. Combines both lists deduplicating to return up to n suggestions.
LetterSession.flush_word() → str
Appends current word to committed words list, clears current word. Called when user presses Space.

12. ml/sentence_generator.py — Rule-Based Sentence Engine

backend/ml/sentence_generator.py

Converts an ASL gloss sequence + NMM signals into grammatical English when Watsonx is unavailable. Implements core ASL→English grammatical transformations.

Lookup tables

_PRONOUNS (I/ME/YOU/HE/SHE/WE/THEY → English), _FUTURE_MARKERS (WILL/GONNA/…), _PAST_MARKERS (FINISH/ALREADY/…), _NEG_MARKERS (NOT/NO/NEVER), _WH_GLOSSES (WHO/WHAT/WHERE/…), _ADJECTIVES (40 adjectives), _VERBS (70 verbs), _CONTRACTIONS (15 pairs like "do not"→"don't"), _ARTICLES (20 countable nouns that get "the").

_gloss_to_words(gloss_sequence) → list[str]
Strips whitespace, converts to uppercase, removes empty items. Preserves hyphenated compounds like THANK-YOU.
_map_gloss(gloss) → str
Maps a single uppercase gloss to its English equivalent:
  • Pronoun lookup (ME → "I")
  • Multi-word compounds (THANK-YOU → "thank you")
  • Fingerspelled abbreviations (A-S-L → "ASL")
  • Default: lowercase the gloss
_apply_contractions(text) → str
Uses regex word-boundary matching to replace all "do not" → "don't", etc. Makes output sound more natural.
_select_copula(subject, is_past) → str
Returns the correct "to be" form: "am" for I, "is" for he/she/it, "are" for you/we/they, and the past forms "was"/"were".
_split_aux(verb_phrase, subject, is_past) → (aux, bare_verb)
Splits a verb phrase into auxiliary + bare verb for question inversion. If the phrase already starts with a known auxiliary (will, did, do, etc.) it splits there. Otherwise synthesises: "did" for past, "does" for third-person singular, "do" otherwise.
_add_articles(words) → str
Prepends "the " to any word in the _ARTICLES set (common countable nouns), then joins with spaces.
generate_sentence(gloss_sequence, nmm_summary) → str
Main public function. Full pipeline:
  1. Normalise glosses via _gloss_to_words().
  2. Read NMM thresholds (eyebrow_raise → yes/no question, eyebrow_furrow → WH question, head_shake → negation, head_nod → affirmation, mouth_open → intensifier).
  3. Detect tense: FUTURE/WILL → modal "will"; PAST/FINISH → "did".
  4. Categorise content tokens: pronouns, verbs, adjectives, nouns.
  5. Select subject (first pronoun, then first noun, then first token).
  6. Determine copula need (adjective without verb → "is/am/are").
  7. Handle negation: invert verb phrase to "won't", "didn't", or "don't".
  8. Branch on sentence type: WH-question, yes/no question, or declarative.
  9. Apply contractions, clean whitespace, capitalise first letter + standalone I.

13. ml/model.py — LSTM Architecture

backend/ml/model.py

class TemporalAttention(nn.Module)

__init__(hidden_size)
Creates a single Linear layer attn: Linear(hidden_size → 1, bias=False). This projects each time step's hidden state to a scalar score.
forward(x: Tensor) → Tensor
x shape: (batch, T, H) → out shape: (batch, H)
Computes attention weights via softmax over T dimension, then returns weighted sum of hidden states — a single context vector per sample.

class GestureBridgeLSTM(nn.Module)

__init__(num_classes)
Architecture:
  • lstm1: BiLSTM(input=218, hidden=128, bidirectional=True) → output 256 per step
  • drop1: Dropout(0.4)
  • lstm2: BiLSTM(input=256, hidden=64, bidirectional=True) → output 128 per step
  • drop2: Dropout(0.3)
  • attention: TemporalAttention(128) → context 128
  • fc1: Linear(128 → 256) + BatchNorm1d + Dropout(0.4)
  • out: Linear(256 → num_classes)
forward(x) → Tensor
x: (batch, 45, 218) → logits: (batch, num_classes)
Passes through both BiLSTM layers, temporal attention, FC+BN+Dropout, and final linear projection. Returns raw logits (softmax applied at inference time in predictor.py).
build_model(num_classes, learning_rate) → (model, optimizer, criterion)
Factory for training: creates GestureBridgeLSTM, Adam optimizer (lr=1e-3, weight_decay=1e-4), CrossEntropyLoss.
load_saved_model(model_path, num_classes) → GestureBridgeLSTM
Loads saved weights with weights_only=True and sets eval mode. Used in evaluation scripts.

14. ml/utils/landmarks.py — Feature Extraction

backend/ml/utils/landmarks.py

Defines all constants for the 218-dim feature vector and functions to extract features from MediaPipe Holistic results.

Feature vector layout constants

SINGLE_HAND_SIZE = 21 × 3 = 63     (wrist-normalised xyz per landmark)
HANDS_SIZE       = 63 × 2 = 126    (left + right)
POSE_SIZE        = 8 × 3 = 24      (shoulder-normalised, 8 key joints)
FACE_SIZE        = 9 × 3 = 27      (nose-anchored, 9 face mesh points)
VELOCITY_SIZE    = 3                (dominant wrist Δxyz)
INTERACTION_SIZE = 2                (fingertips→lips dist, fingertips→nondominant palm dist)
ACCEL_SIZE       = 3                (Δvelocity)
NMM_SIZE         = 10               (brow raise/furrow, head motion Δ, mouth, smile, depth, asymmetry)
FINGER_ANGLE_SIZE= 15               (joint angles rad: 3 joints × 5 fingers)
WRIST_ORIENT_SIZE= 4                (quaternion w,x,y,z)
BODY_DIST_SIZE   = 4                (fingertips to chin/chest/abdomen/nondominant)

TOTAL            = 218
build_hands_solution(...) → mp.solutions.holistic.Holistic
Creates a MediaPipe Holistic instance. static_image_mode=False enables tracking (faster for video); True for frame-by-frame dataset processing.
_normalize_hand(coords) → ndarray[63]
Subtracts wrist position (landmark 0) to make coordinates relative to wrist. Divides by max absolute coordinate (scale normalisation). Makes representation translation and scale invariant.
_extract_pose(pose_landmarks) → ndarray[24]
Takes 8 upper-body joints (shoulders, elbows, wrists, hips). Centres on the midpoint between shoulders; scales by inter-shoulder distance.
_extract_face(face_landmarks) → ndarray[27]
Takes 9 face mesh points (nose, lips, chin, jaw, forehead). Centres on nose tip; scales by face height (forehead to chin).
_interaction_features(left_lms, right_lms, face_lms, pose_lms, shoulder_scale) → ndarray[2]
Computes two body-relative distances:
  • dist_to_lips: Euclidean distance from dominant-hand fingertip centroid to lips (mouth contact signs).
  • dist_to_palm: Distance from dominant fingertips to non-dominant palm (two-handed signs).
Both normalised by shoulder scale.
_extract_nmm(face_landmarks, prev_head_*, face_scale) → (ndarray[10], yaw, pitch, roll)
Extracts 10 non-manual marker scalars from the face mesh:
  • [0] Eyebrow raise (eye–brow gap relative to face scale)
  • [1] Eyebrow furrow (inner brow distance vs baseline)
  • [2] Head pitch delta (nodding)
  • [3] Head yaw delta (shaking)
  • [4] Head roll delta (tilting)
  • [5] Mouth open (lip gap)
  • [6] Smile width (corner distance vs face width)
  • [7] Lip protrusion (z-depth)
  • [8] Cheek width
  • [9] Brow asymmetry (left vs right raise difference)
Also returns current yaw/pitch/roll for next-frame delta computation.
_extract_finger_angles(hand_landmarks) → ndarray[15]
Computes joint angles (in radians) at 15 joint triplets: 3 joints per finger × 5 fingers. Uses the dot-product cosine formula, clamped to [-1, 1] before arccos.
_extract_wrist_orientation(hand_landmarks) → ndarray[4]
Derives a unit quaternion from the hand plane. Uses wrist→middle-knuckle as forward vector, index-to-pinky as right vector, and their cross product as up. Converts 3×3 rotation matrix to quaternion (Shepperd's method). Encodes hand rotation in 3D space.
_body_distance_features(dominant_lms, base_lms, face_lms, pose_lms, shoulder_scale) → ndarray[4]
Distance from dominant hand fingertip centroid to: chin [0], chest midpoint [1], abdomen midpoint [2], and non-dominant hand palm [3]. All shoulder-scale normalised.
extract_landmarks_from_frame(frame_bgr, hands_solution, prev_dominant_wrist, prev_velocity, prev_head_state, dominant_is_right) → (vec218, wrist, velocity, head_state)
Main per-frame feature extraction. Called during training and dataset building.
  1. Converts BGR→RGB, processes with MediaPipe Holistic.
  2. Extracts and normalises left/right hand landmarks.
  3. Computes shoulder scale for body normalisation.
  4. Computes wrist velocity (current wrist − previous wrist).
  5. Computes acceleration (current velocity − previous velocity).
  6. Calls all 8 feature extraction functions.
  7. Concatenates all into a single 218-dim float32 array.
  8. Asserts length == 218 (guards against feature size drift).
  9. Returns vec + updated state for next frame's delta computation.
extract_sequence_from_video(video_path, sequence_length, hands_solution, dominant_is_right) → ndarray(sequence_length, 218)
Reads a video file, samples exactly sequence_length frames using np.linspace over the full duration. For each sampled frame, calls extract_landmarks_from_frame(). If a frame produces all zeros (no detection), repeats the last valid frame. Used during dataset preprocessing.

15. ml/utils/preprocess.py — Inference Preprocessing

backend/ml/utils/preprocess.py
pad_or_truncate(sequence, length=45) → ndarray
If the sequence has ≥ length frames, returns first length rows. If shorter, pads with zero rows at the end. Ensures fixed temporal dimension for the LSTM.
normalize_sequence(sequence) → ndarray
Identity function — returns the sequence unchanged (per-frame normalisation already done by landmarks.py at extraction time).
preprocess_landmark_sequence(sequence, mean=None, std=None) → ndarray
Full inference pipeline: pad_or_truncate → optional z-score ((seq-mean)/(std+1e-8)) → expand_dims(axis=0) to add batch dimension. Returns (1, 45, 218) float32 array ready for the model.
preprocess_frame(frame) → ndarray [DEPRECATED]
Legacy pixel-based preprocessor from an earlier version. Kept only for import compatibility with old scripts. Not used in production path.

16. Training Scripts Overview

ml/train.py

Trains the GestureBridgeLSTM gesture model. Loads database/asl_data.npz (pre-extracted 218-dim sequences), splits into train/val, trains with Adam optimizer + CrossEntropyLoss, saves gesture_model.pt, labels.json, model_meta.json, normalizer.npz.

ml/train_asl_letter.py

Trains the scikit-learn letter classifier. Loads raw hand landmark CSVs or collected data, fits StandardScaler, trains RandomForest or SVC, evaluates accuracy, saves asl_letter_model.joblib + asl_letter_scaler.joblib + asl_letter_meta.json.

ml/collect_asl_data.py

Interactive OpenCV + MediaPipe tool for recording ASL sign videos. Captures frames, extracts 218-dim sequences per frame, saves to npz dataset.

ml/build_asl_dataset.py

Processes a directory of labelled sign videos using extract_sequence_from_video(), building the training dataset NPZ file.

ml/preprocess_dataset.py

Re-processes the raw dataset to the current 218-dim feature format. Run after changing feature extraction code.

ml/evaluate.py

Loads saved model, runs evaluation on a test split, prints accuracy, confusion matrix, and per-class F1 scores.

ml/inspect_dataset.py

Utility to check dataset dimensions, label distribution, and sample counts per class.
