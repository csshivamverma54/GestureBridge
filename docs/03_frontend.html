Data flow: Every page reads auth state from AuthContext via useAuth() and settings from SettingsContext via useSettings(). API calls go through services/api.js which automatically attaches JWT from localStorage. The JWT is set/cleared via AuthContext.login() / logout().

4. services/api.js — API Layer

frontend/src/services/api.js

All backend communication goes through this file. Uses Axios with a single instance. All functions return Axios Promises.

Axios instance setup

BASE_URL = import.meta.env.VITE_API_URL || '' — empty in dev (Vite proxy handles routing to Flask:5000) and production (same origin). Only set explicitly for external CDN/Render split deployment. 30-second timeout.

Interceptors

Request interceptor
Before every request, reads gb_token from localStorage and injects Authorization: Bearer <token> header. This means no component needs to manually attach auth headers.
Response interceptor (error handler)
On any 401 response, clears gb_token and gb_user from localStorage and redirects to /login. Handles expired or invalidated JWTs globally without per-page error handling.

Helper functions

getErrorMessage(error) → string
Extracts the most useful message from an Axios error. Priority: error.response.data.error → .data.message → error.message → fallback string.

Auth functions

registerUser(data) — POST /register
data: { name, email, password }. Returns 201 on success.
loginUser(data) — POST /login
data: { email, password }. Returns { token, message }.
getProfile() — GET /profile
Returns { name, email } for the authenticated user. Requires JWT.

Gesture prediction functions

predictGesture(userId, gesture, nmm) — POST /predict
gesture: 2D array (T×218). nmm: { eyebrow_raise, eyebrow_furrow, head_shake, head_nod, mouth_open }. Returns { predicted_text, confidence, top5, warning? }.
predictLetter(landmarks, indexTipXY) — POST /predict-letter
landmarks: 63-element flat array. indexTipXY: optional [x,y] for J/Z trajectory detection. Returns { letter, confidence, top5, is_dynamic }.
generateSentence(glosses, nmm) — POST /generate-sentence
glosses: string[]. Returns { sentence, source }.
generateLetterSentence(letters) — POST /generate-letter-sentence
letters: string (e.g. "hlo"). Returns { sentence, suggestions[] }.
getModelStatus() — GET /model/status
Returns { model_loaded, num_classes, sample_labels, letter_model_loaded, letter_classes, letter_accuracy }.
reloadModel() — POST /model/reload
Hot-reloads ML models from disk. Returns success/error JSON.

History & Text-to-Sign functions

getHistory(userId) — GET /history/:userId
userId is the user's email. Returns array of translation records.
textToSign(text, language) — POST /text-to-sign
Returns { words[], coverage, total_words, found_words }.
getVocabulary() — GET /text-to-sign/vocabulary
Returns full WLASL supported word list.
videoUrl(videoPath) → string | null
Prepends BASE_URL if set (external deploy); otherwise returns the path as-is for same-origin resolution.
bestVideoUrl(wordEntry) → string | null
Selects the best video URL from a word entry: prefers local Flask stream (video_url), falls back to CDN (external_url).

AI (Watsonx) functions

improveText(text) — POST /ai/improve-text
Polishes a raw sign-to-text result into fluent English. Returns { improved }.
getLearningTip(word) — POST /ai/learning-tip
Returns { word, tip, fun_fact } from Watsonx Llama-3.
getSentenceInsights(translations) — POST /ai/sentence-insights
translations: string[]. Returns { insights } — a prose paragraph of learning observations.
getAiStatus() — GET /ai/status
Returns { configured: bool, model: string|null }.

10. components/ProtectedRoute.jsx

14. pages/Auth.jsx

frontend/src/pages/Auth.jsx

Handles both login and registration in a single tabbed component (~1500 lines). Implements email OTP verification, Google OAuth, and guest access.

GestureBridge icon (hand + text SVG). white=true renders in white for dark backgrounds.

A custom 6-cell OTP input component. Renders six individual single-character text inputs. Features:

Counts down from seconds to 0 when active=true using setInterval. Returns timeLeft (number). Used to show "Resend in 45s" during OTP flow. Cleans up interval on unmount.

Registration flow (3 steps)

handleRegisterStep1()
Validates name/email/password are non-empty. Calls api.post('/otp/send', {email}). On success, sets otpStep=1 and starts the 45-second resend countdown.
handleVerifyOtp()
Calls api.post('/otp/verify', {email, code: otpValue}). On success (valid=true), sets otpStep=2 (verified, show register form submit).
handleFinalRegister()
Calls registerUser({name, email, password}). On success, auto-calls loginUser({email, password}) to get a JWT, stores via login(token, user), navigates to /dashboard.
handleResendOtp()
Resends OTP and resets countdown. Disabled while countdown is active.

Login flow

handleLogin()
Calls loginUser({email, password}). On success, calls login(data.token, {name, email}) from AuthContext, then navigates to /dashboard.

Google OAuth

handleGoogleLogin()
Redirects browser to /auth/google (Flask endpoint). The response is a 302 to Google's consent screen. After consent, Google redirects back to /auth/google/callback (Flask) which issues JWT and redirects to /auth/callback (React AuthCallback page).

Guest login

handleGuestLogin()
Calls loginAsGuest() from AuthContext (sets in-memory only state), navigates to /dashboard.

17. pages/SignToText.jsx

frontend/src/pages/SignToText.jsx

The most complex component (~1500 lines). Camera capture, MediaPipe integration, real-time ML inference, sentence building, TTS. Supports two modes: Sign Mode (full gestures → words) and Spell Mode (fingerspelling → letters).

Module-level constants

ConstantValuePurpose
SEQUENCE_LENGTH45Primary FIFO buffer depth (frames)
MAX_SEQUENCE_LENGTH60Upper window for temporal overlap
STABLE_FRAMES3Consecutive matching predictions to commit a word
CAPTURE_MS150Inference poll interval (~6.7 Hz)
CONFIDENCE_THRESHOLD0.85Min probability to commit a sign word
REST_FRAMES30Rest frames to trigger sentence end
VELOCITY_REST_THRESH0.010Wrist speed below this = resting
COOLDOWN_MS800Post-commit pause before next prediction
LETTER_CONF_THRESH0.70Min probability to commit a letter
LETTER_STABLE_FRAMES4Consecutive letter frames before commit
LETTER_COOLDOWN_FRAMES10Frames to skip after letter commit

Module-level feature vector constants

Mirrors the Python landmarks.py layout: SINGLE_HAND_SIZE=63, HANDS_SIZE=126, POSE_SIZE=24, FACE_SIZE=27, VELOCITY_SIZE=3, INTERACTION_SIZE=2, ACCEL_SIZE=3, NMM_SIZE=10, FINGER_ANGLE_SIZE=15, WRIST_ORIENT_SIZE=4, BODY_DIST_SIZE=4, LANDMARK_VECTOR_SIZE=218. Offsets OFF_VEL, OFF_ACCEL, OFF_NMM are derived from these.

Utility functions (module-level)

speakText(text, locale)
Uses window.speechSynthesis Web Speech API. Cancels any current speech, creates a new SpeechSynthesisUtterance with the given locale. Does nothing if synthesis is unavailable.
normalizeHand(lms) → Float32Array[63]
Browser-side mirror of Python's _normalize_hand(). Takes MediaPipe hand landmark array, subtracts wrist, divides by max absolute coordinate.
mirrorHandLandmarks(lms) → array
Negates the x-coordinates to handle mirrored webcam display. Applied when dominant hand is determined to be left.
extractPose(plms) → Float32Array[24]
Browser mirror of _extract_pose(). 8 upper-body joints, shoulder-centred and scaled.
extractFaceSpatial(flms) → Float32Array[27]
Browser mirror of _extract_face(). 9 face points, nose-anchored.
computeInteraction(domLms, baseLms, flms, sc) → Float32Array[2]
Fingertip-to-lips and fingertip-to-palm distances. Same logic as Python.
computeBodyDist(domLms, baseLms, flms, plms, sc) → Float32Array[4]
Distances to chin/chest/abdomen/non-dominant palm.
extractFingerAngles(lms) → Float32Array[15]
15 joint angles using dot-product cosine formula.
extractWristQuat(lms) → Float32Array[4]
Orientation quaternion from hand plane (Shepperd's method).
extractNMM(flms, prevYaw, prevPitch, prevRoll) → {vec[10], yaw, pitch, roll}
10 non-manual marker scalars from face mesh: eyebrow raise/furrow, head motion deltas, mouth open, smile, lip protrusion, cheek width, brow asymmetry.
buildFrameVector(results, dominantIsRight, prevWrist, prevVel, headState) → {vec218, wrist, vel, headState}
Main per-frame assembly function. Calls all the above helpers and concatenates into the full 218-dim Float32Array. Returns updated state for next frame's deltas.
vecSpeed(vec) → number
Reads the velocity slice [OFF_VEL..OFF_VEL+3] and returns L2 norm (wrist speed). Used for motion state detection.
nmm2label(nmm) → string
Converts NMM summary object to a human-readable string like "Raised eyebrows (Y/N question) + Head nod" for the UI overlay.
loadScript(src) → Promise
Dynamically injects a <script> tag and returns a Promise that resolves on load or rejects on error. Used to lazily load MediaPipe CDN scripts.

Key functions

startCamera() — async, useCallback
Main initialization function. Steps:
  1. Calls loadScript() for holistic.js, camera_utils.js, drawing_utils.js CDN scripts (loadStep 1→3).
  2. Creates new window.Holistic({...}) with onResults callback.
  3. Creates new window.Camera(videoRef.current, { onFrame, width:640, height:480 }).
  4. Sets loadStep=4 (Ready).
  5. Starts setInterval(captureLoop, CAPTURE_MS) for inference polling.
onResults callback (inside startCamera)
Called by MediaPipe Holistic on every processed frame. Steps:
  1. Calls buildFrameVector(results, ...) to get 218-dim vec.
  2. Runs handedness calibration: counts which hand is more often dominant over first CALIBRATION_FRAMES=20 frames.
  3. Detects fingerspelling mode: checks if base hand is stable AND dominant hand has micro-motion.
  4. Computes wrist speed and updates motionState.
  5. Pushes vec to the 60-frame FIFO buffer via typed array rotation.
  6. Draws landmark overlays (hand + face + pose connections) onto canvas.
captureLoop (setInterval body)
Runs every CAPTURE_MS=150ms:
  1. In Sign Mode: If motion state is 'resting' for REST_FRAMES → trigger generateSentenceFromGlosses(). Otherwise, slice the FIFO to get 45 frames and call predictGesture(user.email, sequence, nmmSummary). On success, check confidence ≥ threshold and stable count. If 3 consecutive same-word confident predictions → commit to glossSequence.
  2. In Spell Mode / FS Mode: Extracts dominant hand's 63 landmarks, calls predictLetter(landmarks63, indexTipXY). Debounces same letter over LETTER_STABLE_FRAMES. On commit, appends letter to letterWord.
generateSentenceFromGlosses() — async
Called when resting. Posts to /generate-sentence (or falls back to /ai/gloss-to-english). On success, appends {raw: glosses.join(" "), improved: null, source} to sentence state. Speaks the result via speakText(). Clears glossSequence for next sentence.
teardown()
Cleans up on camera stop or unmount: clears the capture interval, calls camera.stop(), calls holistic.close(), stops all MediaStream tracks from the video element.
stopCamera() — useCallback
Calls teardown() then sets cameraActive=false.

Handler functions

handleImprove(idx) — async
Calls improveText(sentence[idx].raw) (POST /ai/improve-text). Updates the specific sentence entry with improved text from Watsonx.
handleUndoGloss()
Removes the last item from glossSequence (slice 0,-1).
handleClearGloss()
Clears the entire glossSequence array.
handleUndoSentence()
Removes the last completed sentence from the sentence array.
handleClearAll()
Clears both glossSequence and sentence arrays.
handleCopy()
Copies all completed sentences (improved text preferred, then raw) joined with spaces to clipboard via navigator.clipboard.writeText().
flushFsBuffer()
Finalises current fingerspelled word: calls generateLetterSentence(letterWord) to get AI word match, appends to sentence, resets letterWord.
handleLetterCommitWord()
Manual trigger for flushFsBuffer (when user clicks "Commit Word").
handleLetterClearWord()
Erases current letter buffer without committing.
handleApplySuggestion(suggestion)
Replaces current letterWord with a clicked suggestion from the autocomplete list.

Profile tab

Loads user data from getProfile() on mount (if not guest). Shows name and email. Submits changes via updateUser(partial) (AuthContext). Guest users see a read-only view.

Security tab

Password change form. Validates new password ≥ 8 chars and matches confirmation. Sends change request to backend (PATCH /profile or similar). Not applicable for Google OAuth users (shows notice).

Appearance tab

Uses SettingRow for each option:

  • Theme: Toggle switch, calls toggleTheme().
  • Sign Language: <select> dropdown (ASL/ISL/Hindi/Marathi), calls updateSettings({language}).
  • Recognition Mode: Radio-style toggle (Word / Letter), calls updateSettings({recognitionMode}).
  • Capture Interval: Range slider 100–500ms, calls updateSettings({captureInterval}).
  • Confidence Threshold: Range slider 0.3–0.99, calls updateSettings({confidenceThreshold}).

Privacy tab

Toggle for notifications and privacyMode settings, each via updateSettings(). Privacy mode note: currently suppresses history saving (future feature).
