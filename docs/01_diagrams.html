3. Activity Diagram — Text-to-Sign Flow

  [User opens /text-to-sign]
          │
          ▼
  ┌────────────────────────────┐
  │  User types / speaks text  │  ← STT via Web Speech API (optional)
  └────────────┬───────────────┘
               │
               ▼
  ┌──────────────────────────────┐
  │  POST /text-to-sign          │
  │  { text: "I am happy" }      │
  └────────────┬─────────────────┘
               │
               ▼
  ┌──────────────────────────────┐
  │  _tokenise(text)             │
  │  → ["i","am","happy"]        │
  └────────────┬─────────────────┘
               │
               ▼
  ┌──────────────────────────────────────────────────┐
  │  _resolve_tokens() for each token:               │
  │  1. Check bigram (2-word phrase) in _WORD_LOOKUP │
  │  2. Exact single-word lookup                     │
  │  3. _fuzzy_match() → stem candidates             │
  │     then difflib close-match (cutoff 0.80)       │
  └────────────┬─────────────────────────────────────┘
               │
               ▼
  ┌──────────────────────────────────────────────────┐
  │  For each matched word:                          │
  │  • found=true  → video_url = /video/{id}         │
  │                  OR external_url (CDN)           │
  │  • found=false → display "not found" indicator  │
  └────────────┬─────────────────────────────────────┘
               │
               ▼
  ┌──────────────────────────────────┐
  │  Response: { words[], coverage,  │
  │             found_words, total } │
  └────────────┬─────────────────────┘
               │
               ▼
  ┌──────────────────────────────────────┐
  │  Frontend: render word chips         │
  │  Select first available word         │
  └────────────┬─────────────────────────┘
               │
               ▼
  ┌───────────────────────────────────────┐
  │  Video player loads mp4               │
  │  ┌──────────────────────────────────┐ │
  │  │ local /video/{id} available?     │ │
  │  │  YES → stream from Flask         │ │
  │  │  NO  → try external_url (CDN)    │ │
  │  └──────────────────────────────────┘ │
  └────────────┬──────────────────────────┘
               │
               ▼
  ┌────────────────────────────────┐
  │ Auto-advance ON?               │
  │  YES → onEnded → next word     │
  │  NO  → user clicks Next        │
  └────────────────────────────────┘

      │               │               │ [if Watsonx] generate(prompt)         │

14. State Machine — Sign Recognition Engine

The motion states managed inside SignToText.jsx during live prediction.

                       [camera starts]
                              │
                              ▼
                    ┌─────────────────┐
               ┌───►│     IDLE        │◄──── [no hands detected]
               │    │ (no hands)      │
               │    └────────┬────────┘
               │             │ hands detected
               │             ▼
               │    ┌─────────────────┐
               │    │   SIGNING       │◄──── wrist speed > VELOCITY_REST_THRESH
               │    │ (motion active) │
               │    └────────┬────────┘
               │             │ speed < VELOCITY_REST_THRESH
               │             ▼
               │    ┌─────────────────┐
               │    │    HOLDING      │  ←  brief pause mid-sign
               │    │ (still, <30fr) │
               │    └────────┬────────┘
               │             │ >30 consecutive rest frames
               │             ▼
               │    ┌─────────────────┐
               │    │   RESTING       │  ← sentence boundary detected
               │    │ (sentence end)  │
               │    └────────┬────────┘
               │             │ triggers POST /generate-sentence
               └─────────────┘ then resets glossSequence

Prediction commit logic (Sign Mode):
  ┌──────────────────────────────────────────────────────┐
  │  Per-inference-tick:                                  │
  │  1. Confidence ≥ 0.85 ?                              │
  │     NO  → do not commit                              │
  │     YES → compare to lastCommitted word              │
  │  2. Same as lastCommitted?                           │
  │     YES → stableCount++                             │
  │     NO  → stableCount = 1, update candidate          │
  │  3. stableCount ≥ STABLE_FRAMES (3)?                │
  │     YES → commit gloss to glossSequence[]           │
  │            → start cooldown 800ms                    │
  │            → reset stableCount                       │
  └──────────────────────────────────────────────────────┘

Fingerspelling auto-detect (Spell Mode auto-switch):
  baseHand stable (>10 frames) AND
  dominantHand micro-motion (0.025 > speed < 0.06)
  → fsMode = true (purple UI tint)
  
  baseHand moves (bSpeed > 0.03) → fsMode = false
